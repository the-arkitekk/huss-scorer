# Example scans

`demo-scans.js` holds ten scans of the author's trial 3 (from `samples/real`, scaled to 150 dpi) and an example project with one structure: a remembered room, ceiling 4 m, opposite wall 7 m. Main menu → **Try with example scans** loads them and starts an Open mode session (rater code DEMO); nothing is uploaded.

Made with `node tests/tools/make-demo.js`.
